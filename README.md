# Тестирование интернет-магазина

[![hexlet-check](https://github.com/milyaeiner15112005-hub/qa-engineer-project-84/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/milyaeiner15112005-hub/qa-engineer-project-84/actions)

Учебный проект по ручному тестированию веб-приложения. В рамках проекта протестирован интернет-магазин: составлены требования, написаны тест-кейсы, найдены и описаны баги, проведено регрессионное тестирование.

Первая версия веб-приложения: https://products-store-ru.hexlet.app/ 

Вторая версия веб-приложения: https://products-store-v2-ru.hexlet.app/ 

## Содержание репозитория

1. `about.yml` - описание профессиональных навыков тестировщика
2. `requirements.yml` - описание функциональных, нефункциональных и неявных требований проекта
3. `test-cases.yml` - подробные тест-кейсы для проведения тестирования
4. `testing-report.yml` - результат прохождения тест-кейсов с отметкой об их успешности или провальности
5. `bugreports.yml` - подробное описание дефектов и шагов по их воспроизведению
6. `regress-report.yml` - отчет о проведенном регрессионном тестировании и новые баг-репорты
7. `screenshots.md` - скриншоты, приложенные к баг-репортам

## Стек

- Ручное тестирование
- YAML и Markdown для оформления документации
- GitHub Issues для баг-репортов
- Яндекс Браузер DevTools
- Регрессионное тестирование
